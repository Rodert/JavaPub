## 二、保姆级创建步骤

### Step 1：访问平台并登录

1. 浏览器打开 [Instabox 官网](https://instabox.sh/)，平台 Logo 是一个小箱子图标。
2. 点击右上角的登录入口。
3. 选择 **Google** 或 **GitHub**，按页面提示完成授权登录。

> 登录后，侧边栏可能会展示“创建 API Key”“密钥”“Webhook”等入口，以及一些付费选项。本教程的手动创建流程无需配置这些功能。

### Step 2：创建免费云主机

1. 在平台主页点击 **“创建（Create）”** 按钮。
2. 填写主机名称，例如 `mycloudpc`。
3. 系统类型选择默认配置即可。演示中平台也提供安卓机镜像，可以按需选择。
4. 资源规格选择 **“中等（Medium）”：4 核 CPU / 8GB 内存 / 20GB 磁盘**。演示中的另外两档更高配置需要付费会员，创建前注意确认免费标识。
5. 时长设置保持默认的 **30 分钟**。
6. 确认配置后，点击底部的 **“创建”**。

视频演示中，等待大约 **10 秒钟**，机器就完成了部署并启动。实际等待时间会受到平台负载等因素影响。

## 四、核心避坑指南与使用限制

### 1. 留意 30 分钟时长与空闲回收规则

创建页面中的默认时长是 **30 分钟**。原教程还提到，机器长时间无命令输入、无窗口交互时，可能触发空闲回收。

**创建时长和空闲超时属于不同设置，不能仅凭“30 分钟”就认定只要有操作便能一直运行。** 使用前请查看当前实例的到期时间、空闲超时说明，以及平台是否提供官方延长时长的功能。

原教程提到过保活方案，但脚本心跳是否有效、是否符合当前平台规则，需要另行确认。运行任务时，应按平台支持的方式管理时长，并及时保存结果。

### 2. 标称 20GB 磁盘，实际可用空间可能只有约 4GB

虽然配置标注为 **20GB 磁盘**，但系统镜像和基础依赖也会占用空间。原教程中的环境已占用约 16GB，留给用户的空间大约只有 **4GB**。

不同镜像的占用可能不同。安装大型软件或拉取 Docker 镜像之前，可以先在终端检查：

```bash
df -h
```

重点查看目标文件系统的 `Avail`（可用空间）和 `Use%`（使用率），避免任务执行到一半才发现磁盘不足。

### 3. 注意 8 小时运行上限的具体口径

原教程提到，免费实例单次连续运行最多 **8 小时**，达到上限后会自动暂停。不过，“单次连续运行上限”和“每日累计额度”是不同概念，具体以平台当前说明为准。

**保活不代表可以 7 × 24 小时永久运行。** 暂停后能否重启、是否保留文件、是否还有剩余额度，也需要在平台确认。
